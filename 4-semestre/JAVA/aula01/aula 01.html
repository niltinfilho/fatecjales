Programação Orientada a Objetos com Java

Conceitos iniciais de POO

Nesta aula serão apresentados os fundamentos necessários para compreender a organização de programas Java por meio de classes e objetos, estabelecendo a base para conteúdos posteriores como encapsulamento, herança, polimorfismo, MVC e DAO.

Fundamento

Classe

Modelo utilizado para definir dados e comportamentos de uma entidade.

Execução

Objeto

Instância concreta criada a partir da estrutura definida por uma classe.

Comportamento

Método

Ação que um objeto pode executar dentro do sistema.

1. Introdução

O que é Programação Orientada a Objetos?

A Programação Orientada a Objetos, ou POO, é um paradigma de desenvolvimento no qual o sistema é organizado a partir de estruturas que representam entidades, conceitos e responsabilidades.

Ideia central:

Em vez de concentrar todo o código em uma sequência extensa de comandos, os dados e comportamentos relacionados são agrupados em objetos.

Sistema acadêmico

Aluno, Professor, Disciplina, Turma, Matrícula e Nota podem ser representados por classes diferentes.

Sistema comercial

Cliente, Produto, Pedido, Pagamento e Estoque também podem ser representados por objetos.

2. Organização do software

Por que utilizar POO?

Organização

As responsabilidades do sistema podem ser separadas em classes, reduzindo a concentração de código em um único ponto.

Manutenção

Alterações tendem a ficar restritas às classes responsáveis pelo comportamento modificado.

Reutilização

Uma classe bem projetada pode ser utilizada diversas vezes e em diferentes partes da aplicação.

Modelagem

Conceitos do problema podem ser traduzidos para estruturas de software mais fáceis de compreender.

3. Mudança de abordagem

Programação procedural × POO

Abordagem procedural

O foco principal está na sequência de operações e em funções que manipulam dados.

cadastrarAluno();
calcularMedia();
mostrarAluno();

Orientação a objetos

Os comportamentos são associados ao objeto responsável por eles.

Aluno aluno = new Aluno();

aluno.calcularMedia();
aluno.mostrarDados();

5. Classes

Classe: o modelo do objeto

Uma classe descreve quais informações e comportamentos estarão disponíveis para os objetos criados a partir dela.

public class Pessoa {

    String nome;
    int idade;

}

Neste momento existe apenas a definição de como uma Pessoa será representada. Ainda não foi criada uma pessoa específica.

6. Objetos e instâncias

Objeto: uma ocorrência concreta

Um objeto é criado a partir de uma classe. Diversos objetos podem ser gerados utilizando o mesmo modelo.

Pessoa pessoa1 = new Pessoa();
Pessoa pessoa2 = new Pessoa();

pessoa1.nome = "Ana";
pessoa1.idade = 20;

pessoa2.nome = "Carlos";
pessoa2.idade = 35;

Os dois objetos pertencem à mesma classe, mas armazenam estados diferentes.

9. Estado

Atributos

Os atributos armazenam as características e informações associadas a cada objeto.

public class Carro {

    String marca;
    String modelo;
    String cor;
    int ano;
    double velocidade;

}

Embora todos os objetos Carro tenham esses atributos, os valores armazenados podem ser diferentes em cada instância.

10. Dados em memória

O estado de um objeto

Carro carro = new Carro();

carro.marca = "Toyota";
carro.modelo = "Corolla";
carro.velocidade = 0;

O conjunto dos valores atuais dos atributos forma o estado do objeto.

carro.velocidade = 80; // o estado foi alterado
11. Comportamentos

Métodos

Se os atributos representam o que um objeto possui, os métodos representam aquilo que ele faz.

public class Carro {

    double velocidade;

    void acelerar() {
        velocidade = velocidade + 10;
    }

}

O método acelerar() modifica o próprio estado do objeto.

12. Comunicação com objetos

Chamando um método

Carro carro = new Carro();

carro.acelerar();
carro.acelerar();

Se cada chamada aumentar a velocidade em 10 km/h, após duas chamadas o objeto possuirá velocidade igual a 20.

Operador ponto:

objeto.atributo acessa um dado e objeto.metodo() solicita a execução de um comportamento.

13. Exemplo completo

Classe Carro

public class Carro {

    String marca;
    String modelo;
    int ano;
    double velocidade;

    void acelerar() {
        velocidade = velocidade + 10;
    }

    void frear() {
        velocidade = velocidade - 10;
    }

    void mostrarDados() {
        System.out.println("Marca: " + marca);
        System.out.println("Modelo: " + modelo);
        System.out.println("Ano: " + ano);
        System.out.println("Velocidade: " + velocidade);
    }
}
14. Execução

Utilizando a classe no método main

public class Principal {

    public static void main(String[] args) {

        Carro carro = new Carro();

        carro.marca = "Toyota";
        carro.modelo = "Corolla";
        carro.ano = 2025;

        carro.mostrarDados();
        carro.acelerar();
        carro.acelerar();
        carro.mostrarDados();
    }
}
15. Métodos mais flexíveis

Métodos com parâmetros

Um método pode receber informações no momento em que é executado.

void acelerar(double valor) {
    velocidade = velocidade + valor;
}
carro.acelerar(20);
carro.acelerar(50);

O parâmetro valor permite reutilizar o mesmo método para diferentes quantidades.

16. Resultados

Métodos com retorno

double obterVelocidade() {
    return velocidade;
}

O tipo double antes do nome do método indica que um valor desse tipo será devolvido.

double velocidadeAtual = carro.obterVelocidade();

System.out.println(velocidadeAtual);

18. Inicialização

Construtores

O construtor é executado no momento da criação do objeto e pode ser utilizado para garantir que a instância já seja criada com informações necessárias.

public class Aluno {

    String nome;
    int idade;

    public Aluno(String nome, int idade) {
        this.nome = nome;
        this.idade = idade;
    }
}
Aluno aluno = new Aluno("Carlos", 20);
19. Referência ao próprio objeto

A palavra-chave this

public Aluno(String nome) {
    this.nome = nome;
}

this.nome

Refere-se ao atributo nome pertencente ao objeto atual.

nome

Refere-se ao parâmetro recebido pelo construtor.

20. Exemplo integrado

Classe Produto

public class Produto {

    String nome;
    double preco;
    int quantidade;

    public Produto(String nome, double preco, int quantidade) {
        this.nome = nome;
        this.preco = preco;
        this.quantidade = quantidade;
    }

    double calcularValorEstoque() {
        return preco * quantidade;
    }

    void mostrarProduto() {
        System.out.println("Produto: " + nome);
        System.out.println("Preço: R$ " + preco);
        System.out.println("Quantidade: " + quantidade);
    }
}

22. Proteção dos dados

Introdução ao encapsulamento

Até aqui os atributos foram acessados diretamente. Em aplicações orientadas a objetos, é comum restringir esse acesso utilizando private.

public class Produto {

    private String nome;
    private double preco;

}

Encapsulamento permite que a própria classe controle como seus dados podem ser consultados ou modificados.

23. Acesso controlado

Getters e Setters

public class Produto {

    private String nome;

    public void setNome(String nome) {
        this.nome = nome;
    }

    public String getNome() {
        return nome;
    }
}
produto.setNome("Notebook");
System.out.println(produto.getNome());
24. Regra de negócio

Por que controlar o acesso?

O acesso controlado permite impedir estados inválidos.

Um preço negativo, por exemplo, normalmente não representa um estado válido para um produto.

public void setPreco(double preco) {

    if (preco >= 0) {
        this.preco = preco;
    }
}

A classe passa a ser responsável por proteger a consistência dos próprios dados.

25. Visão geral

Os quatro pilares da POO

Abstração

Selecionar e representar somente as características relevantes para o problema.

Encapsulamento

Proteger dados e definir formas controladas de acesso ao estado interno.

Herança

Permitir que uma classe aproveite características e comportamentos definidos em outra.

Polimorfismo

Permitir diferentes comportamentos por meio de uma mesma estrutura de referência.

Nesta aula, o foco principal permanece em classe, objeto, atributo, método, construtor e uma introdução ao encapsulamento.

26. Exercício guiado

Conta Bancária

Criar a classe ContaBancaria com os atributos titular, numero e saldo.

Implementar os métodos depositar(), sacar() e mostrarSaldo().

public class ContaBancaria {

    String titular;
    int numero;
    double saldo;

    void depositar(double valor) {
        saldo += valor;
    }

    void sacar(double valor) {
        saldo -= valor;
    }

    void mostrarSaldo() {
        System.out.println("Saldo: R$ " + saldo);
    }
}

28. Pensamento orientado a objetos

Existe um problema nesse saque?

void sacar(double valor) {
    saldo -= valor;
}

O código permite sacar qualquer valor, mesmo quando o saldo é insuficiente.

void sacar(double valor) {

    if (valor <= saldo) {
        saldo -= valor;
    } else {
        System.out.println("Saldo insuficiente.");
    }
}

Um objeto não precisa apenas guardar dados. Ele também pode garantir as regras de negócio relacionadas a esses dados.
