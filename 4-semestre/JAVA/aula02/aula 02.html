Encapsulamento, Construtores, Getters e Setters

Nesta aula serão aprofundados os mecanismos usados para proteger o estado dos objetos, controlar o acesso aos atributos e criar instâncias consistentes.

Encapsulamento

Proteção e controle do estado interno.

1. Retomada

O ponto de partida

Na aula anterior foram estudados classe, objeto, atributo, método, instanciação e construtor.

public class Aluno {
    String nome;
    int idade;
}

Aluno aluno = new Aluno();
aluno.nome = "Maria";
aluno.idade = 20;

O problema é que qualquer parte do sistema poderia executar aluno.idade = -50;.

2. Conceito principal

O que é encapsulamento?

Encapsulamento é o princípio que protege o estado interno de um objeto e controla como seus dados podem ser consultados ou modificados.

Sem controle

public double preco;
produto.preco = -1000;

Com encapsulamento

private double preco;

Outras classes deixam de alterar o atributo diretamente.

3. Visibilidade

Modificadores de acesso

ModificadorAcesso
publicQualquer classe com acesso ao objeto.
privateSomente dentro da própria classe.
protectedClasse, pacote e subclasses.
sem modificadorClasses do mesmo pacote.

Nesta aula o foco principal será public e private.

4. Proteção de estado

Atributos privados

public class Aluno {
    private String nome;
    private int idade;
}

Depois dessa alteração, aluno.nome = "Maria"; não será permitido fora da classe.

O acesso deverá ocorrer por meio de métodos públicos definidos pela própria classe.

5. Consulta

Getter

Getter é um método usado para consultar um atributo privado.

public String getNome() {
    return nome;
}
System.out.println(aluno.getNome());
6. Alteração

Setter

Setter é um método utilizado para alterar um atributo de maneira controlada.

public void setNome(String nome) {
    this.nome = nome;
}
aluno.setNome("Maria");
7. Acesso controlado

Getter e Setter juntos

public class Aluno {
    private String nome;

    public String getNome() {
        return nome;
    }

    public void setNome(String nome) {
        this.nome = nome;
    }
}
aluno.setNome("Maria");
System.out.println(aluno.getNome());
8. Consistência

Validação utilizando Setter

public void setIdade(int idade) {
    if (idade >= 0) {
        this.idade = idade;
    } else {
        System.out.println("Idade inválida.");
    }
}

A classe passa a impedir que o objeto entre em um estado inválido.

9. Organização

Quem deve validar?

Regra fora da classe

if (idade >= 0) {
    pessoa.idade = idade;
}

A regra pode ser esquecida ou duplicada.

Regra dentro da classe

pessoa.setIdade(idade);

A própria classe centraliza a regra.

10. Exemplo

Classe Produto encapsulada

public class Produto {
    private String nome;
    private double preco;

    public String getNome() {
        return nome;
    }

    public void setNome(String nome) {
        this.nome = nome;
    }

    public double getPreco() {
        return preco;
    }

    public void setPreco(double preco) {
        if (preco >= 0) {
            this.preco = preco;
        }
    }
}
11. Utilização

Manipulando Produto

Produto produto = new Produto();

produto.setNome("Notebook");
produto.setPreco(3500);

System.out.println(produto.getNome());
System.out.println(produto.getPreco());

O código externo não precisa saber como os dados estão armazenados internamente.

12. Inicialização

O construtor

O construtor é executado quando uma nova instância é criada.

Aluno aluno = new Aluno();

O trecho Aluno() representa a chamada ao construtor.

13. Construção explícita

Criando um construtor

public class Aluno {
    private String nome;
    private int idade;

    public Aluno(String nome, int idade) {
        this.nome = nome;
        this.idade = idade;
    }
}
Aluno aluno = new Aluno("Maria", 20);
14. Estado inicial

Por que utilizar construtores?

Sem construtor parametrizado

Aluno aluno = new Aluno();
aluno.setNome("Maria");
aluno.setIdade(20);

Com construtor

Aluno aluno =
    new Aluno("Maria", 20);

O construtor permite exigir dados essenciais no momento da criação.

15. Consistência

Evitando objetos incompletos

Dependendo do sistema, um aluno sem nome, matrícula ou curso pode não representar um objeto válido.

Aluno aluno = new Aluno(
    "Maria",
    "2026001",
    "Sistemas para Internet"
);

O construtor define quais informações são obrigatórias para a criação.

16. Referência ao objeto

A palavra-chave this

public Aluno(String nome) {
    this.nome = nome;
}

this.nome

Atributo do objeto atual.

nome

Parâmetro recebido pelo construtor.

17. Consistência

Construtor com validação

public Produto(String nome, double preco) {
    this.nome = nome;

    if (preco >= 0) {
        this.preco = preco;
    }
}

O construtor também pode impedir estados inválidos.

18. Evitando duplicação

Reutilizando o Setter no construtor

public Produto(String nome, double preco) {
    this.nome = nome;
    setPreco(preco);
}

A mesma regra de validação é reutilizada durante a criação e nas alterações posteriores.

19. Comportamento do Java

Construtor padrão

Quando nenhum construtor é declarado, Java oferece automaticamente um construtor sem parâmetros.

public class Pessoa {
    private String nome;
}

Pessoa pessoa = new Pessoa();

Ao declarar um construtor parametrizado, o construtor vazio deixa de ser criado automaticamente.

20. Atenção

Construtor parametrizado e construtor vazio

public Pessoa(String nome) {
    this.nome = nome;
}

Nesse caso, o código abaixo deixa de ser válido:

Pessoa pessoa = new Pessoa();

Será necessário usar o construtor existente ou declarar também um construtor sem parâmetros.

21. Diferentes formas de criar

Sobrecarga de construtores

public Pessoa() { }

public Pessoa(String nome) {
    this.nome = nome;
}

public Pessoa(String nome, int idade) {
    this.nome = nome;
    this.idade = idade;
}

A classe passa a oferecer várias formas válidas de criação.

22. Identificação

Assinatura de métodos e construtores

Pessoa()

Sem parâmetros.

Pessoa(String nome)

Um parâmetro.

Pessoa(String nome, int idade)

Dois parâmetros.

Como o Java escolhe?

Pelos argumentos informados na chamada.

23. Mesmo nome

Sobrecarga de métodos

public class Calculadora {

    public int somar(int a, int b) {
        return a + b;
    }

    public double somar(double a, double b) {
        return a + b;
    }
}
calculadora.somar(10, 20);
calculadora.somar(10.5, 20.8);
24. Encapsulamento real

Nem todo atributo precisa de Setter

Considere o saldo de uma conta bancária.

private double saldo;

public double getSaldo() {
    return saldo;
}

É possível permitir a consulta sem permitir uma alteração direta por setSaldo().

25. Regras de domínio

Controlando o saldo corretamente

public void depositar(double valor) {
    if (valor > 0) {
        saldo += valor;
    }
}

public void sacar(double valor) {
    if (valor > 0 && valor <= saldo) {
        saldo -= valor;
    }
}

O saldo muda somente por operações coerentes com a conta.

26. Exemplo completo

Classe ContaBancaria

public class ContaBancaria {
    private String titular;
    private int numero;
    private double saldo;

    public ContaBancaria(String titular, int numero) {
        this.titular = titular;
        this.numero = numero;
        this.saldo = 0;
    }

    public void depositar(double valor) {
        if (valor > 0) saldo += valor;
    }

    public void sacar(double valor) {
        if (valor > 0 && valor <= saldo) saldo -= valor;
    }

    public String getTitular() { return titular; }
    public int getNumero() { return numero; }
    public double getSaldo() { return saldo; }
}
27. Execução

Utilizando ContaBancaria

ContaBancaria conta =
    new ContaBancaria("Maria", 1234);

conta.depositar(1000);
conta.sacar(200);

System.out.println(conta.getTitular());
System.out.println(conta.getSaldo());

Saída esperada: Maria e 800.0.

29. Projeto inadequado

Encapsulamento superficial

public class Conta {
    private double saldo;

    public void setSaldo(double saldo) {
        this.saldo = saldo;
    }
}

Ainda seria possível executar conta.setSaldo(-100000);.

O uso de private precisa estar acompanhado de regras coerentes.

30. Exemplo prático

Classe Funcionario

public class Funcionario {
    private String nome;
    private String cargo;
    private double salario;

    public Funcionario(
        String nome,
        String cargo,
        double salario
    ) {
        this.nome = nome;
        this.cargo = cargo;
        setSalario(salario);
    }
}
31. Validação

Salário e aumento

public void setSalario(double salario) {
    if (salario >= 0) {
        this.salario = salario;
    }
}

public double getSalario() {
    return salario;
}

public void aumentarSalario(double percentual) {
    if (percentual > 0) {
        salario = salario +
                  salario * percentual / 100;
    }
}
32. Execução

Testando Funcionario

Funcionario funcionario =
    new Funcionario(
        "Carlos",
        "Desenvolvedor",
        3000
    );

System.out.println(funcionario.getSalario());
funcionario.aumentarSalario(10);
System.out.println(funcionario.getSalario());

Saída esperada: 3000.0 e depois 3300.0.

33. Atividade guiada

Classe Produto

Criar uma classe Produto com os atributos privados nome, preço e quantidade.

Adicionar construtor, getters e setters adequados.

Implementar calcularValorEstoque(), adicionarEstoque() e removerEstoque().

34. Atividade guiada

Regras do Produto

  • O preço não poderá ser negativo.
  • A quantidade não poderá ser negativa.
  • Não poderá ser removida quantidade maior que o estoque.
  • Somente valores positivos poderão ser adicionados.
Produto produto =
    new Produto("Teclado", 150, 10);

produto.adicionarEstoque(5);
produto.removerEstoque(3);

System.out.println(produto.getQuantidade());

Resultado esperado: 12.

35. Atividade prática individual

Sistema simples de Veículo

Criar a classe Veiculo com os atributos privados:

marca, modelo, ano e velocidade.

O construtor deverá receber marca, modelo e ano. A velocidade inicial deverá ser zero.

36. Comportamentos

Métodos da classe Veiculo

acelerar(double valor)

Aceitar somente valores maiores que zero.

frear(double valor)

Impedir velocidade abaixo de zero.

getVelocidade()

Consultar a velocidade atual.

Getters

Consultar marca, modelo e ano.

37. Resultado esperado

Utilizando Veiculo

Veiculo carro =
    new Veiculo(
        "Honda",
        "Civic",
        2024
    );

carro.acelerar(50);
carro.frear(20);

System.out.println(carro.getVelocidade());

Resultado esperado: 30.0.

38. Desafio adicional

Velocidade máxima

private double velocidadeMaxima;

Modificar acelerar() para impedir que o veículo ultrapasse esse limite.

Se a velocidade atual for 180 km/h, a máxima for 200 km/h e a aceleração solicitada for 50 km/h, o resultado deverá ser 200 km/h.

39. Atenção

Erros comuns

Esquecer o this

nome = nome;

O atributo não é alterado corretamente.

Acessar private diretamente

produto.preco = 100;

Não será permitido fora da classe.

Setter para tudo

Nem todo atributo deve ser alterável diretamente.

Duplicar validação

Regras devem ser centralizadas e reaproveitadas.
